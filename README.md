### 🛠️ Featured Project

**[Distributed API Gateway with Redis-based Rate Limiting](https://github.com/manu101018/Distributed-rate-limiter-gateway)**
A horizontally scalable API gateway built with TypeScript, Node.js, Redis, Docker, and Nginx.
- Implements fixed-window, sliding-window, and token-bucket rate limiting using atomic Redis Lua scripts.
- Enforces a single shared per-identity rate limit across 3 stateless gateway replicas, preventing race conditions.
- Pluggable factory/strategy architecture with configuration-driven route matching and fail-open behavior for Redis outages.
- Instrumented with Prometheus and Grafana; load-tested at **1M requests** — **2,250 req/s**, **p50 42ms**, **p95 205ms**, **0 client errors**.
